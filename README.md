# LPN and RN Tutor

Static web experience supporting nursing exam practice and NCLEX-style study.

## Project at a glance

- **Purpose:** Static web experience supporting nursing exam practice and NCLEX-style study.
- **Repository:** https://github.com/Omoluabi1003/lpn-rn-tutor
- **Status:** Repository documentation foundation. Review implementation before describing features as production-ready.

Open `index.html` in a browser or serve this directory using a local static server.
